# 🍞 Padaria Infinity

Uma aplicação web moderna desenvolvida para apresentar os produtos e serviços de uma padaria de forma profissional, intuitiva e responsiva.

O projeto foi criado com foco em experiência do usuário, design moderno e presença digital para pequenos negócios.

# 💡 Objetivo do Projeto

O objetivo deste projeto foi desenvolver uma aplicação visualmente atrativa para representar digitalmente uma padaria moderna, permitindo uma navegação agradável e fortalecendo a presença online do negócio.

Além disso, o projeto também foi utilizado para aprimorar habilidades em:

* Desenvolvimento Front-End
* Responsividade
* Estruturação de interfaces
* Organização visual
* Publicação de aplicações web

# 📂 Como Executar o Projeto

```bash
# Clone o repositório
git clone https://github.com/VanessadoSantos/infinity-padaria-app

# Abra o projeto
cd infinity-padaria-app
```

Depois basta abrir o arquivo `index.html` no navegador.
